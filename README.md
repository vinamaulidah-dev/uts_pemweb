# UTS Pemrograman Web - Invofest

Proyek ini adalah hasil pengerjaan Ujian Tengah Semester (UTS) mata kuliah Pemrograman Web. Aplikasi ini terdiri dari dua bagian utama:
- **Frontend**: Menggunakan React + TypeScript + Vite (Berada di folder `Frondend_Invofest`).
- **Backend**: Menggunakan Node.js + Express + Prisma (Berada di folder `Backend_Invofest`).

## Cara Menjalankan

### Backend
1. Masuk ke folder `Backend_Invofest`
2. Install dependensi dengan perintah `npm install`
3. Jalankan server dengan perintah `npm run dev`

### Frontend
1. Masuk ke folder `Frondend_Invofest`
2. Install dependensi dengan perintah `npm install`
3. Jalankan aplikasi dengan perintah `npm run dev`
